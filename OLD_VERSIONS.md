# Old Versions

Ronja versions before 0.10.0 ship as a single archive for all platforms.
To run one of them, you need a [Java runtime](https://adoptium.net)
installed, and the `java` command on your `PATH`:

* Ronja versions 0.7.0 and earlier require Java 8.
* Ronja versions 0.8.x require Java 11.
* Ronja versions 0.9.x require Java 17+.

From version 0.10.0, each release has one archive per platform, and each
archive includes the Java runtime that Ronja needs.

To install an old version, download it from the GitHub
[releases page](https://github.com/dykstrom/ronja/releases), unzip it into
a directory of your choice, and follow the [installation](README.md#installation)
steps in the README.
